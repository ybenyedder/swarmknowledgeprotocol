The Omni-Swarm Protocol (OSP)

Stateless, SLM-driven, Peer-to-Peer Knowledge Sharing — with structural termination guarantees and a three-layer hallucination firewall.

The Architecture: Best-of-Breed Synthesis

OSP combines battle-tested patterns from distributed systems (JWT, the actor model, Kademlia, BGP, FIPA, Interledger) with verification techniques from machine learning (NLI entailment, self-consistency sampling, ensemble voting). The result is an exchange mechanism designed for Small LLMs on edge devices in which every query terminates and every accepted answer is verifiable.

From JWT & Actor Model

1. Zero-State Envelopes

Nodes store zero session memory. The full negotiation state travels inside an Ed25519-signed JWS envelope (header.payload.signature). Each packet carries a unique jti nonce and a short exp TTL, so any node can verify authenticity and freshness independently — replay and forgery die at the door.

From Kademlia & BGP

2. Multi-Centroid Routing

No node broadcasts. Each node advertises a codebook of its top-K RAG centroids, quantized to int8 (a 384-dim embedding shrinks to 384 bytes), so routing tables stay tiny on edge hardware. This is the centroid-similarity pattern validated for zero-shot task routing [R13][R11], cheap enough to run on a frozen embedding backbone [R12]. Queries route only to nodes whose centroids align with the intent, and BGP's path-vector rule (never appear twice in your own path) makes routing loops structurally impossible. Centroids are not static: verified outcomes drift each advertised centroid toward the query regions where the node actually delivered [R14].

From FIPA & Interledger

3. Contracting Auctions with Gas

SLMs never dump raw answers. They bid with a composite of elicited, measurable signals — verbalized confidence [R4], semantic certainty [R1], and reputation — never raw logits, which are miscalibrated by construction [R6]. Each bid carries a conformal coverage guarantee [R3]: a distribution-free statistical bound, not a gut feeling. Every hop burns one unit of Gas; when Gas hits zero the packet backtracks home with an explicit failure notice. Negotiation rounds must contract toward agreement or the negotiation aborts.

From NLI & Ensemble Learning

4. Hallucination Firewall

Three independent verification layers: a semantic-entropy gate before any bid is placed [R1] — cheap enough for edge hardware via single-pass linear probes [R2] — local entailment checking of every payload against its cited sources [R5], and a quorum vote with a provenance-diversity rule so one bad document echoed by many nodes can never reach consensus.

The Lifecycle of an OSP Query

How two nodes negotiate meaning without ever opening a persistent connection — and how the origin verifies what it receives.

01

PROPOSE (Multi-Centroid Routing)

Node A builds a JWS envelope with gas = G, its int8-quantized intent vector, and an empty trail. It consults its centroid codebook and forwards to the single best-matching neighbor — not to everyone. Every hop repeats this and decrements Gas. Node A also registers the query on its own nodes: it probes the top-K routed nodes in parallel (default K = 3).

02

BID (Semantic-Entropy Gate)

Node B's SLM runs closed-book retrieval: generation is permitted only over retrieved chunks, and every claim must cite a chunk_hash. Before bidding, B samples itself k times and clusters the samples by meaning (via bidirectional entailment), then computes semantic entropy over the meaning clusters [R1] — token agreement is not enough; two samples can agree lexically while diverging in meaning. On edge hardware, the cheap variant applies: a linear probe on hidden states predicts the entropy in a single forward pass [R2]. High entropy → B places no bid at all — a node unsure of its own meaning exits the auction instead of poisoning it. Otherwise B bids a composite score with provenance, a verbalized confidence elicited in a dedicated pass [R4], a conformal coverage guarantee [R3], and an optional CLARIFY offer.

03

ALIGN (Contracting Semantic Lock)

Node A's SLM maps its ontology onto B's ("hydraulic pump → industrial_water_pump_v2"). OSP follows the hybrid pattern that now dominates the OAEI campaigns: embedding prefiltering to propose candidate correspondences, then an LLM pass to refine and justify each one [R7][R8]. Because LLMs are known to hallucinate plausible-but-wrong correspondences in domain-specific matching [R9], every mapping entry must carry evidence: both concept IRIs plus their definitional snippets — and it is validated against the local KG before being accepted [R10]. Each clarify round must shrink the mapping distance: dn+1 ≤ γ·dn, at most C rounds — otherwise the negotiation aborts with MISMATCH. Once locked, A requires a quorum (default 2 of 3 probes) whose answers agree semantically and cite diverse sources.

04

RESOLVE (Hash-Addressable Payload)

The winning node ships the answer in JSON-LD together with the cited chunks themselves (within a size budget). The origin can therefore verify the answer against its evidence without ever trusting the responder's word about its own content.

05

VERIFY (Local Entailment & Reputation)

The origin runs a tiny NLI pass: answer claims ⊆ cited evidence. Groundedness g ≥ 0.8 → accepted and the responder's reliability score rises. g < 0.8 → rejected, an RFO (Request-Failure) packet returns down the trail, and the responder's reputation decays. Every outcome updates an EWMA reliability that weights all future bids — and the responder's realized groundedness is audited against the coverage its conformal guarantee promised [R3], so systematic over-bidding shows up statistically before it shows up as bad answers.

Failure is never silent: at any step, gas exhaustion, loop detection, or a stalled alignment emits an RFO backtracked along the recorded trail, so the origin always learns the outcome within ≤ 2G hops.

Every message is a signed JWS compact serialization. The signature covers the exact payload bytes; receivers verify signature, freshness (exp), and replay (jti cache) before any processing.

Convergence & Termination Guarantees

A routing layer for unreliable SLMs is only useful if it cannot livelock. OSP's convergence rests on four structural rules — each one turns "probably terminates" into "cannot fail to terminate."

C1

Gas is strictly monotonic → termination is structural

A node MUST decrement Gas by exactly 1 before forwarding any packet and MUST emit an RFO at Gas = 0. Gas is a bounded non-negative integer that strictly decreases on every transition, so the hop count is ≤ G by construction. No scheduling, luck, or cooperation is required — this is a measure function, not a heuristic.

C2

Path-vector loop freedom → cycles cannot bounce forever

A node that finds its own id in negotiation_trail drops the packet (LOOP_DETECTED). A per-node LRU cache of seen jti values (TTL ≥ 2× the exp window) drops duplicates and replays. Even before Gas runs out, the trail cannot revisit a node.

C3

Alignment is a contraction → negotiation cannot oscillate

Each clarify round must report a strictly smaller mapping_distance: the sequence is bounded below by 0 and decreases geometrically, so it converges. A round that fails to shrink the distance aborts with MISMATCH instead of looping — "no progress" is treated as an answer.

C4

Quorum with provenance diversity → consensus is not an echo chamber

ACCEPT requires a quorum q of k probes whose payload embeddings are pairwise-similar (≥ θ) and whose cited chunk_hash sets span ≥ k−1 distinct sources. Votes citing the same hash count as a single vote. This is what stops one corrupted document propagating k copies of itself into a unanimous "consensus."

bid = w₁·semantic_certainty + w₂·retrieval_similarity + w₃·verbalized_confidence + w₄·reputation (Σwᵢ = 1 — never logits [R4][R6]) H = −Σ_clusters p(c)·log p(c) (semantic entropy over meaning clusters [R1]) H high → suppress bid · edge variant: SEP linear probe, 1 forward pass [R2] bid carries P(grounded) ≥ 1 − α (conformal stop@k — distribution-free [R3]) d(n+1) ≤ γ · d(n), γ < 1 → clarify rounds ≤ min( log(d₀/ε) / log(1/γ), C ) P(quorum error) = 3p²(1−p) + p³ (k=3, q=2, per-node residual rate p) = 2.8 % when p = 10 % r_i ← (1−α)·r_i + α·outcome (EWMA → converges to true reliability)

Putting it together — every query ends in one of five modes, all of them explicit:

Outcome Trigger What is on the wire
RESOLVED Quorum q of k verified bids, groundedness ≥ 0.8 ALIGN → RESOLVE → VERIFY OK; reputations rise
MISMATCH Alignment stops contracting within C rounds RFO(MISMATCH) backtracked along the trail
GAS_EXHAUSTED Gas hits 0 mid-route RFO(GAS) backtracked — no silent drops
LOOP_DETECTED Own id in trail, or jti already cached RFO(LOOP); packet dies
NO_QUORUM Timeout with < q agreeing verified bids Retry with decayed threshold τ ← τ − δ, at most R times, then NACK

Liveness. If the knowledge exists within reach and the overlay is connected, threshold decay (τ − δ per retry, bounded by R) eventually accepts weak-but-grounded bids — so liveness never compromises the termination bound of G + C + R rounds.

Fault honesty. OSP fully tolerates crash faults. Byzantine behavior is contained, not prevented: lying bids are filtered by the firewall below, and a node suppressing RFOs merely forces the origin's local timeout — a bounded wait, never a hang.

The Hallucination Firewall

An SLM's raw confidence score is uncalibrated — a bid of 0.9 means nothing [R6]. OSP therefore never routes on logits. Instead it detects hallucination with three independent, measurable layers — semantic entropy [R1], entailment [R5], and calibrated consensus — so a fabricated answer must survive grounding, entailment, and consensus to be accepted.

L1

Semantic-entropy gate (responder, before any bid)

Closed-book rule: the SLM generates only over retrieved chunks, and every claim must cite ≥ 1 chunk_hash. An answer with no provenance is not a weak answer — it is not an answer. Then the semantic-entropy gate [R1]: sample k times, cluster the samples by meaning (bidirectional entailment), and compute entropy over the meaning clusters. This beats token-level self-consistency because it catches confabulation at the meaning level — the failure mode where a model paraphrases its own error consistently. On edge hardware the full clustering is replaced by a semantic-entropy probe: a linear head over hidden states that predicts the entropy in one forward pass, no extra sampling [R2]; SelfCheckGPT's NLI-variant consistency check [R5] is the fallback when no probe is trained. High entropy → the node suppresses its own bid entirely: self-detected instability removes the node from the auction instead of poisoning it.

L2

Local entailment (origin, on every payload)

The RESOLVE payload carries its cited chunks, so the origin runs a tiny NLI pass: groundedness g = entailed claims / total claims. g < 0.8 → the payload is rejected, an RFO is returned, and the responder's reputation decays. This is the load-bearing layer: verification is local and hash-addressable — the origin never takes the responder's word about its own content.

L3

Swarm consensus (network-wide)

Independent nodes make uncorrelated errors, so a quorum vote multiplies residual hallucination rates down: with per-node residual rate p (after L1+L2), k = 3 and q = 2 turn p = 10 % into ≈ 2.8 %. The provenance-diversity rule keeps the binomial bound honest: agreement only counts when evidence is independent, because "three nodes citing the same wrong manual" is one opinion, not three.

Reputation closes the loop. Each node keeps an EWMA reliability r per peer, updated with every verification outcome and used as a multiplicative weight on bids. A node that hallucinates converges to r → 0 and stops winning auctions — the swarm's defense is economic, not just logical.

Known Limits

Stated plainly, because a protocol that hides its failure modes is itself a hallucination:

  • Independence is an assumption. The L3 bound degrades if nodes share corrupted sources beyond what the diversity rule detects (e.g., two wrong manuals that agree with each other).
  • Byzantine RFO suppression cannot be fully prevented on hostile paths; the fallback is the origin's bounded local timeout.
  • Centroid staleness: advertised codebooks lag behind RAG updates; routing recall degrades gracefully but is not instant.
  • Calibration drift: bid weights (w₁…w₄) and thresholds (τ, θ, g) need periodic re-validation on real traffic, or the firewall slowly goes soft [R6]. Conformal guarantees additionally assume calibration and query distributions stay exchangeable [R3] — distribution shift weakens the bound silently.

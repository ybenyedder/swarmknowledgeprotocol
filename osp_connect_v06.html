Design decisions worth defending

  • The origin node is N1 and never generates (v0.5 generation-once): the MCP server negotiates, but the winning responder generates. A provider-backed node only spends remote tokens when it wins an auction.
  • Providers are downstream of the firewall, not part of it (REQ-F-02): evidence chunks travel to the provider in a quoted envelope with an instruction to answer only from evidence; the origin verifies the returned text against the cited hashes. A lying provider produces REJECTED + reputation decay — proven by the adversarial stub.
  • Capability-aware routing (REQ-F-03): PROPOSE goes to N2/N3 nodes first; N1 nodes fill remaining slots as relays and pre-bidders only.
  • One transport seam: InMemoryHub.send/join/peers is the entire transport interface today. WhatsApp (v0.5 hub mode) and BLE mesh implement the same three functions later — no core changes.

3. Discovery design

Lease-based directory, TOFU-pinned

A record = {node_id, class, key bundle, endpoints, transports, topic codebook, lease}. Registration pins the first signing key per node (TOFU); a different key is rejected until an explicit repin(). Announcements carry a jti — replays rejected. Leases (default 900 s) expire silently from lookup: a departed node disappears rather than lying about availability. Bootstrap order: configured seeds → mDNS (future, same interface) → directory. The class field (N1/N2/N3) is what makes thin phones useful: they announce, relay, and pre-bid without ever paying for a generation.

4. Test Plan

LayerWhatStatus
L0 — unit rules Packet validation in isolation: gas=0 → RFO, expired TTL → RFO, self-in-trail → LOOP_DETECTED, replayed jti → silent drop. implemented (6 tests)
L1 — convergence modes The five modes as executable scenarios: RESOLVED (T1, 2 nodes), NO_QUORUM (single bid at q=2), MISMATCH (evidence drift BID→ALIGN), plus REJECTED via adversarial provider. Gas exhaustion bounded — no livelock. implemented (5 tests)
L2 — firewall & tiers Confabulating provider rejected + reputation decay; provenance diversity collapses echo votes; prompt-injection neutralized in the envelope. implemented (3 tests)
L3 — classes, budgets, providers N1 delegation to N3; budget exhaustion → abstention; provider swap invariance (local vs scripted-remote); T2 never remote by default; ../LLMprovider adapter degrades gracefully when absent. implemented (5 tests)
L4 — discovery & MCP conformance Lease expiry, top-k ranking, TOFU pinning, discovery replay; initialize → tools/list → tools/call in-process + real stdio smoke. implemented (8 tests)
L5 — property/fuzz Random topologies (seeded): invariant every query ends ≤ G+C+R rounds in an explicit mode; random RAG/RFO-suppression chaos: origin wait stays bounded (falls back to timeout). planned — next iteration
L6 — interop & hardware Two server processes over a real transport; then the v0.5 §7 benchmark on target phones. Numbers stay "modeled" until this layer runs. planned — blocked on transports
